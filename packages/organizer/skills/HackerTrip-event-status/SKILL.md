# 查询主办方赛事状态

使用提交时同一组主办方编号和提交密钥。缺凭证时，引导用户到 HackerTrip 小程序「我的 → 我要举办 → 发起赛事与项目 → 让 AI 帮我提交」复制指令；入口名称随频道变化。只在自己的电脑端使用密钥，不公开、打印或保存到 Git。

需要 Node.js ≥18、HackerTrip CLI ≥1.4.0。

```bash
npx hackertrip@latest event-status --organizer-no <主办方编号> --submit-key <提交密钥>
```

凭证也支持 HACKERTRIP_ORGANIZER_NO、HACKERTRIP_SUBMIT_KEY 环境变量；默认接口地址已内置。别用 login 的选手同步会话代替主办方凭证。

结果最多返回本账号最近 20 条提交记录，包含名称、草稿 ID、审核状态、提交时间、待补信息、退回备注。准确转述返回值：待提交表示尚未送平台审核；平台审核中也不等于已公开，公开状态以平台审核及实际上架为准。

没有记录时说明可能尚未提交、换了账号或目标记录不在最近 20 条中，引导回小程序「我的 → 我要举办 → 赛事&项目管理」核对。不要自动新建草稿。

错误凭证或密钥已重置：回小程序重新复制，禁止猜密钥；网络或服务失败可稍后重试只读查询。被拒绝时整理返回的补充项给主办方，修改或删除仍由小程序完成。

旧配对码查询也支持 `--pair-code <6位码> --sync-token <uploadToken>`，受有效期限制；优先长期编号密钥。

CLI 只保存 `pending_submission`（待提交）草稿，不代主办方提交平台审核。主办方在小程序「赛事&项目管理」打开详情、编辑并保存后，亲自点击「提交平台审核」。平台审核中的草稿可查看、不可修改；已上线内容归入正式赛事与项目。
